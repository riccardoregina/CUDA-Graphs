# Presentation: Kernel Batching with CUDA Graphs

This directory contains the slides for the presentation "Kernel Batching with CUDA Graphs: Replication Study and Performance Validation".

## Building the Presentation

To compile the presentation, you can use `pdflatex`:
```bash
pdflatex slides.tex
```
